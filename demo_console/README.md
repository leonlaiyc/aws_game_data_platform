# Live AWS operation demo console

This is the recording surface for the two-minute interface walkthrough. It is
not a mock: every result is read from or executed against the deployed AWS
stacks. The localhost server keeps SigV4 credentials out of the browser.

```powershell
.\infra\.venv\Scripts\python.exe .\demo_console\server.py
```

Open `http://127.0.0.1:8787`, then follow the four numbered chapters. For a
clean 16:9 recording, use a 1600 × 900 browser viewport.
